# Directrices de trabajo del proyecto

Estas instrucciones recogen las preferencias del autor y se aplican al trabajo en este directorio.

- La prioridad es completar `proyecto_final/`, cumpliendo la rúbrica y los acuerdos de negocio. Mantener la estructura de entrega indicada por la rúbrica.
- Usar `pset_2/` como fuente de referencia y continuidad del PSet 02. No utilizar `pset-02/` para nuevos desarrollos, rutas de ejecución ni integraciones del proyecto final. El código integrado se ejecuta desde `proyecto_final/`.
- Los laboratorios del curso son una referencia opcional. Priorizar sus patrones de programación o metodología cuando encajen con la lógica del proyecto y ayuden a obtener el resultado buscado. Cuando no encajen, aplicar el criterio técnico y de negocio desarrollado para este proyecto.
- Justificar cada decisión por los requisitos, los datos, la evidencia, la reproducibilidad o las necesidades operativas del proyecto. No justificar una configuración o implementación porque el profesor la utilizó en un ejercicio; tampoco añadir comentarios con esa explicación.
- No tratar el estilo de los laboratorios como obligatorio ni modificar una solución válida únicamente para imitarlo.
- Completar los `TODO` de los laboratorios queda fuera del alcance prioritario. Retomarlos solo si el autor lo solicita después y el avance del proyecto final lo permite.
- Conservar `laboratorios/` como referencia local excluida de Git. El proyecto final debe funcionar sin importar código ni datos desde esa carpeta.
